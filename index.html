Senior Frontend Engineer

Google ✓ Verified
📍 Mountain View, CA · Remote 💼 Full-time 🎓 5+ years experience 📅 Posted 2 days ago 👥 248 applicants

About the Role

We are looking for a talented and experienced Senior Frontend Engineer to join our world-class engineering team at Google. In this role, you will be working on cutting-edge web applications that impact billions of users worldwide. You'll collaborate with exceptional engineers, designers, and product managers to build the next generation of Google's user experiences.

Responsibilities

  • Design, develop, and ship high-quality, scalable frontend features used by millions of users
  • Collaborate with cross-functional teams including design, product, and backend engineering
  • Write clean, maintainable, and well-tested code with a focus on performance
  • Mentor junior engineers and contribute to team growth through code reviews
  • Drive technical decision-making and architecture for frontend systems
  • Contribute to open-source projects and the broader engineering community
  • Participate in on-call rotations and incident response when needed

Requirements

  • 5+ years of professional frontend engineering experience
  • Expert-level proficiency in React, TypeScript, and modern JavaScript (ES6+)
  • Deep understanding of web performance optimization and core web vitals
  • Experience with state management solutions (Redux, Zustand, Jotai)
  • Proficiency with testing frameworks (Jest, React Testing Library, Cypress)
  • Strong understanding of CSS, responsive design, and accessibility (WCAG 2.1)
  • BS/MS in Computer Science or equivalent practical experience

Nice to Have

  • Experience with Next.js, Server Components, and Edge functions
  • Knowledge of WebAssembly or WebGL for high-performance applications
  • Open-source contributions and a strong GitHub profile
  • Experience with design systems and component library creation

Required Skills

React TypeScript Next.js GraphQL Jest Webpack CSS/SCSS Git Redux REST APIs

Benefits & Perks

  • Comprehensive health, dental, and vision insurance for you and dependents
  • 401(k) with generous company matching
  • $5,000 annual learning & development budget
  • Flexible remote work policy with quarterly team offsites
  • Free meals, snacks, and world-class on-site facilities
  • Equity package with accelerated vesting schedule
